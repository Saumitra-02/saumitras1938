# How Breaking Down Work Is Helping

I'm using Sublime Text's PlainTasks extension to break down my work into smaller tasks.

I start with a big task and progressively break it down into micro-steps. For example:

- Understand this PR.
  - Read one file.
    - Read one section of the code.
      - Read one line.

Sometimes, I also set a 5-minute timer for these micro-tasks. Five minutes might seem like a long time for such a small task, but it makes getting started feel much easier.

## The Challenge: Being Consistent

One thing I need to work on is using this strategy consistently.

I tend to discover a strategy that works, follow it for a few days, and then gradually stop using it. Eventually, I forget about it, and the same problems resurface.

Perhaps documenting strategies like this in my blog will help me stick to them.
